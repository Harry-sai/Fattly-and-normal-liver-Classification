# Fatty and Normal Liver Classification

This repository contains the code and experiments for my thesis project, where the goal is to build a machine learning model that **classifies liver images into fatty liver and normal liver** categories.

The project currently focuses on:

- **Segmenting the liver region** from medical images  
- **Developing prediction models** to distinguish between fatty and normal liver images  
- Exploring different architectures and approaches for better accuracy  

## What’s Inside

The repository includes:

- Multiple model implementations (e.g., ResNet-based, EfficientNet variants)
- Segmentation + classification pipeline
- Results and experiments
- Scripts for preprocessing and normalization

## Status

This is an **ongoing thesis work**, and the models are actively being improved.

## Usage

1. Prepare your liver image dataset (segmented/annotated)
2. Train or evaluate classification models
3. Analyze results and metrics
